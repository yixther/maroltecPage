# MarolTec

Página web de portafolio / presentación de la empresa MarolTec.

## Descripción

Sitio web desarrollado con HTML y CSS. Incluye:

- Página de inicio con slider automático
- Sección Nosotros
- Sección Servicios
- Diseño responsive básico

## Tecnologías

- HTML5
- CSS3
- JavaScript (en desarrollo)

## Cómo ver la página

1. Clona el repositorio
2. Abre el archivo `index.html` en tu navegador
